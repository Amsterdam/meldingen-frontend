# Form builder

A plugin to create forms. Uses [the Form.io builder](https://help.form.io/developers/form-development/form-builder).

The `bootstrap` package is a dependency of `@form.io/js`, thus included in this library.  
See [Form Building Example](https://www.npmjs.com/package/@formio/js) from the `@form.io/js` Readme.md
